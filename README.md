# Reasoning Guard 
딥러닝 기반 미확인 공중 표적 정밀 판별 시스템


![Reasoning Guard Logo](./Logo.png)

## 🛡️ Project Overview
현대 전장의 하이브리드 공중 위협에 대응하여, PyTorch 기반의 딥러닝 모델을 활용해 공중 객체(미사일, 전투기, 드론)를 정밀 탐지하고 요격 의사결정(Shoot/Hold)을 지원하는 고신뢰성 소프트웨어 엔진입니다.
